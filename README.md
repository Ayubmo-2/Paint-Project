# Paint Project

A digital painting application I built as a student using Java and Swing.

## What It Does

- Draw on a canvas with different brush shapes and sizes
- Pick any color you want using a color selector
- Simple and easy-to-use interface for creating digital art

## What I Used to Build This

- **Java** - main programming language
- **Swing** - for the GUI and canvas
- **Eclipse** - IDE used to develop the project

## How to Run It

Make sure you have Java installed, then:

1. Open the project in Eclipse (or any Java IDE)
2. Navigate to the `src` folder
3. Run the main class

Or if you want to run it from the terminal:

```bash
cd "Paint Project"
javac -d bin src/**/*.java
java -cp bin Main
```
